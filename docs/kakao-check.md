# 카톡 실측 체크리스트

링크만으로 전달하는 구조라서, 카카오톡이 링크를 어떻게 다루는지가 가장 큰 불확실성이다.
배포가 끝난 뒤 **폰에서** 아래 순서대로 확인하고 결과를 표에 적는다.
하나라도 × 이면 구현을 멈추고 해결안을 상의한다.

## 준비

- 배포 주소: `https://______________________`
- 폰 기종 / OS: `______________________`
- 폰에서 평소 쓰는 기본 브라우저: `Safari` / `Chrome` / `삼성 인터넷` (택1)
- 카톡 버전: `______________________`

초대 링크는 앱에서 만든다: 문항에 답하고 → 리포트 → "지인에게 링크 보내기" → "지인이 나를 부를 이름" 입력 → "링크 복사".
(점수가 나온 축이 하나도 없으면 링크를 만들 수 없다. 축마다 3문항 이상 답해야 점수가 나온다.)
(링크는 `…/r#…` 모양이고 약 400자 안팎이다. 주소가 길어지면 이보다 길어진다.)

## 확인 항목

### ① 초대 링크가 온전히 열리나
1. 초대 링크를 카톡 **나와의 채팅**에 보낸다.
2. 카톡 안에서 링크를 눌러 연다.
3. 기대: 받는 사람 안내 화면("○○님이 보낸 질문지예요")이 정상으로 나온다. 호칭이 맞다.

### ② 진행이 유지되나
1. ①의 화면에서 동의하고 문항 3개에 답한다.
2. 카톡 브라우저를 닫고 같은 링크를 다시 연다.
3. 기대: 답한 3개가 유지되고 4번째부터 이어진다.
   × 이면: 카톡 안 브라우저가 저장소를 유지하지 못하는 것이다. "다른 브라우저로 열기"로 열어서 다시 확인하고, 그 방법이 안내에 필요한지 적는다.

### ③ 답장 링크가 온전히 열리나
1. 받는 사람 화면에서 끝까지 답하고 답장 링크를 만든다.
2. 그 링크를 카톡으로 보낸다 (나와의 채팅).
3. 기대: **처음 질문지를 만든 브라우저**에서 열면 "○○님이 본 모습" 화면이 나온다.

### ④ 링크가 잘리거나 바뀌지 않나
1. 카톡에 보낸 링크를 길게 눌러 복사해서, 브라우저 주소창에 붙여 연다.
2. 기대: 원래 링크와 같은 화면이 나온다.
3. 잘리면: 잘린 지점과 링크 글자 수를 적는다.

### ⑤ 다른 브라우저에서 답장을 열면 안내가 나오나
답변은 만든 브라우저에만 있다. 카톡 안 브라우저에서 질문지를 만들고 사파리/크롬에서 답장을 열면(또는 반대) 내 답변이 없다.
1. 질문지를 만든 브라우저와 **다른** 브라우저에서 답장 링크를 연다.
2. 기대: "이 답장은 링크를 만든 사람이 원래 쓰던 기기의 같은 브라우저에서 열어야 해요…" 안내가 나온다 (오류 화면이 아니라).
3. 이 안내만으로 어떻게 해야 할지 알 수 있는지 적는다. 모르겠다면 × 이다.

### ⑥ 링크 미리보기
- 카톡이 링크를 미리보기 카드로 바꾸면서 주소를 숨기거나 줄이나? 줄여도 눌렀을 때 전체 주소로 열리면 ○.

## 결과를 본 뒤

- 전부 ○: 그대로 공개 준비로 간다.
- ②·⑤ 중 × : 안내 문구나 "다른 브라우저로 열기" 안내를 보강한다.
- ①·③·④ 중 × : 링크가 잘리거나 열리지 않는 것이므로 전달 방식을 다시 설계한다 (예: 더 짧은 링크, 텍스트 코드 붙여넣기). 이 경우 구현을 멈추고 상의한다.
